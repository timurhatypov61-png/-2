## Содержание

В работе выполнен полный конвейер обработки табличных данных 
интернет-магазина средствами Python, NumPy и Pandas:

- формирование исходного набора данных из словаря и сохранение в CSV;
- загрузка данных из CSV-файла и первичный анализ структуры;
- выборка столбцов и строк, фильтрация по нескольким условиям;
- проверка качества данных: поиск пропущенных значений;
- расчёт описательной статистики (среднее, медиана, квартили);
- анализ распределения рейтингов;
- создание производного признака is_high_value;
- группировка заказов по каналу продаж и расчёт средней суммы;
- сортировка результатов группировки;
- построение гистограммы распределения суммы заказов;
- формулировка итогового аналитического вывода.

## Ключевые результаты

- В наборе 15 заказов, 3 пропуска в столбце delivery_time.
- Среднее время доставки — 39.58 мин, медиана — 37.5 мин.
- Средняя сумма заказа: marketplace — 13775 руб., site — 1816.67 руб., 
  app — 1800 руб.
- Обнаружен выброс (заказ на 45000 руб.), который сильно завышает 
  среднее по marketplace.
- 4 заказа имеют стоимость выше 3000 руб.
